# جارویس وب — نسخه آزمایشی

این پوشه یک وب‌اپلیکیشن قابل نصب (PWA) و سرور مرکزی اولیه جارویس است.

## امکانات فعلی
- رابط فارسی و راست‌چین با طراحی واکنش‌گرا
- چت با مدل‌های سازگار با OpenAI Chat Completions
- ورودی گفتار فارسی در مرورگرهای پشتیبان (مانند Chrome اندروید)
- خواندن پاسخ با صدای فارسی موجود در سیستم/مرورگر
- ورود با رمز مشترک و نگهداری کلید مدل فقط روی سرور
- تاریخچه مکالمه مشترک در SQLite
- قابلیت نصب روی صفحه اصلی به شکل PWA

## راه‌اندازی محلی یا روی سرور

برای استقرار، فایل `render.yaml` تنظیمات اولیه Render را فراهم می‌کند. مخزن را به Render متصل کن و Blueprint را بساز؛ سپس مقدارهای محرمانه `JARVIS_ACCESS_PASSWORD` و `AI_API_KEY` را در پنل سرویس وارد کن. برای حفظ تاریخچه، دیسک پایدار سرویس روی `/var/data` به `DATA_DIR` متصل شده است. هزینه و دسترسی دیسک/پلن را پیش از تأیید در Render بررسی کن.
نیازمندی: Node.js 20 یا جدیدتر.

1. وارد پوشه `web` شو و `npm install` اجرا کن.
2. متغیرهای محیطی زیر را در محیط سرور تنظیم کن:
   - `JARVIS_ACCESS_PASSWORD`: یک رمز قوی برای ورود
   - `AI_API_KEY`: کلید API ارائه‌دهنده مدل (فقط روی سرور)
   - `AI_BASE_URL`: پیش‌فرض `https://api.groq.com/openai/v1`
   - `AI_MODEL`: پیش‌فرض `openai/gpt-oss-20b`
   - `DATA_DIR`: پوشه پایدار برای دیتابیس؛ پیش‌فرض `web/data`
3. `npm start` را اجرا کن و آدرس سرور را باز کن.

در سرویس میزبانی، HTTPS و دیسک پایدار برای `DATA_DIR` فعال کن. رمز ورود و کلید API را هرگز داخل فایل‌های `public`، GitHub یا مرورگر قرار نده. نشست‌ها در حافظه سرور نگهداری می‌شوند و با راه‌اندازی مجدد سرور کاربر باید دوباره وارد شود.

## اتصال اندروید به مغز مشترک
این نسخه وب مرحله اول است. APK فعلی هنوز از موتور محلی خودش استفاده می‌کند و به این API مرکزی متصل نشده است. مرحله بعد باید مسیر اتصال امن اندروید به همین `/api/chat` و شناسه کاربر/جلسه پایدار را اضافه کنیم تا هر دو نسخه واقعاً تاریخچه مشترک داشته باشند.

## محدودیت‌های فعلی
- سرور و کلید مدل باید توسط صاحب پروژه روی میزبان پیکربندی شوند؛ این commit به‌تنهایی سایت عمومی را منتشر نمی‌کند.
- تشخیص گفتار به پشتیبانی مرورگر و مجوز میکروفون وابسته است و ممکن است سرویس گفتار مرورگر برای تبدیل گفتار به متن به اینترنت نیاز داشته باشد.
- پاک‌کردن تاریخچه از رابط فعلاً فقط پیام‌های روی صفحه را مخفی می‌کند و دیتابیس مشترک را حذف نمی‌کند.
