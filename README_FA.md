# JARVIS 1.3 — دستیار اندرویدی با هوش مصنوعی محلی

## تصمیم فنی نسخه ۱.۳

- مکالمه با API و کلید سرویس آنلاین در مسیر پاسخ‌گویی وجود ندارد.
- Runtime بومی `llama.cpp` داخل APK کامپایل می‌شود و مدل GGUF را روی خود گوشی اجرا می‌کند.
- مدل پیش‌فرض: `Qwen3-4B-Instruct-2507-Q4_K_M.gguf`، حدود ۲.۵ گیگابایت، مناسب‌تر برای مکالمه و پیروی از دستور نسبت به مدل Base قبلی.
- برنامه در اولین اجرا با تأیید کاربر مدل را از Hugging Face دریافت می‌کند. این دانلود فقط دریافت فایل وزن‌های مدل است، نه API مکالمه. پس از دانلود و بارگذاری، تولید پاسخ آفلاین انجام می‌شود.
- مدل در فضای اختصاصی برنامه نگهداری می‌شود و با حذف برنامه/داده‌های آن پاک خواهد شد.
- ABI فعلی `arm64-v8a` است.

## سازگاری و کیفیت

مدل Qwen3-4B-Instruct-2507 در کوانت Q4_K_M حدود ۲.۵ گیگابایت است. این انتخاب با توجه به اولویت کیفیت مکالمه انجام شده است. روی گوشی ۸ گیگابایتی باید قابل آزمایش باشد، اما سرعت تولید متن، دمای دستگاه و مصرف RAM به نسخه سیستم‌عامل و وضعیت حافظه بستگی دارد و تا اجرای واقعی روی گوشی تضمین نمی‌شود. اگر اندروید به‌علت فشار حافظه برنامه را ببندد، باید context یا مدل کوچک‌تر انتخاب شود.

مدل قبلی کاربر `Qwen3-0.6B-Q4_0.gguf` از نوع Base است و برای دستیار مکالمه‌ای انتخاب ضعیف‌تری است؛ نسخه جدید به‌صورت پیش‌فرض از آن استفاده نمی‌کند. امکان وارد کردن دستی فایل GGUF دیگر از تنظیمات باقی مانده است.

## جریان راه‌اندازی

1. APK را از GitHub Actions بساز و نصب کن.
2. بار اول JARVIS پیام دریافت مدل اصلی را نشان می‌دهد؛ «دانلود و فعال‌سازی» را تأیید کن.
3. دانلود حدود ۲.۵ گیگابایت است و اعلان پیشرفت توسط Download Manager اندروید نمایش داده می‌شود.
4. پس از پایان دانلود، برنامه فایل GGUF را بررسی و موتور محلی را بارگذاری می‌کند.
5. بعد از پیام «مغز هوشمند JARVIS فعال است»، مکالمه متنی و ورودی گفتار برنامه از مدل محلی استفاده می‌کنند.
6. برای آزادسازی RAM، از تنظیمات گزینه «تخلیه مدل از حافظه» را انتخاب کن. روشن‌کردن دوباره AI مدل را بارگذاری می‌کند.

## اینترنت و API

مجوز اینترنت فقط برای دانلود اولیه فایل مدل استفاده می‌شود. در این پروژه هیچ API مکالمه‌ای، کلید API یا درخواست تولید پاسخ به سرور وجود ندارد. پس از دریافت مدل، تولید پاسخ محلی و بدون اینترنت است. موتور تشخیص گفتار اندروید ممکن است بسته به موتور Speech Services نصب‌شده روی گوشی برای تبدیل صدا به متن به اینترنت نیاز داشته باشد؛ این موضوع مستقل از مدل زبانی محلی است.

## ساختار فنی

- `LocalAiEngine.kt`: رابط Kotlin برای بارگذاری، تولید پاسخ و تخلیه مدل.
- `app/src/main/cpp/jarvis_llama.cpp`: پل JNI و حلقه تولید توکن با llama.cpp.
- `app/src/main/cpp/CMakeLists.txt`: دریافت و ساخت نسخه pin شده llama.cpp.
- `MainActivity.kt`: دریافت اولیه مدل، بارگذاری خودکار، حافظه کوتاه مکالمه، گفتار و تأیید فرمان‌های محلی.
- `.github/workflows/build-apk.yml`: ساخت APK در GitHub Actions بدون نیاز به کامپیوتر یا Android Studio کاربر.

## فرمان‌های گوشی و محدودیت‌ها

مدل به‌تنهایی دسترسی سیستمی ندارد. پیشنهاد فرمان باید از allowlist برنامه عبور کند و برای عملیات پشتیبانی‌شده تأیید کاربر لازم است. نسخه فعلی فقط بخشی از فرمان‌های پایه مانند بازکردن برنامه‌ها و صفحه تنظیمات، چراغ‌قوه، صدا، روشنایی و مزاحم نشو را پیاده‌سازی کرده است. تماس، پیامک، مخاطبین، خواندن اعلان‌ها، Dynamic Island واقعی روی سایر برنامه‌ها و شنود دائمی کاملاً مستقل هنوز تکمیل نشده‌اند.

کلمه بیدارباش فعلی از SpeechRecognizer اندروید استفاده می‌کند؛ تضمین بیدارباش آفلاین یا اجرای دائمی در همه شرایط اندروید وجود ندارد.

## ساخت با GitHub از طریق گوشی

روش ساده‌تر با گوشی: یک مخزن جدید بساز، فایل `JARVIS_GITHUB_BOOTSTRAP.yml` را به‌عنوان فایل `.github/workflows/build.yml` در مخزن ایجاد کن، سپس `JARVIS_v1.3_LocalAI_GitHub.zip` را در ریشه مخزن بارگذاری کن. در Actions، workflow با نام `Build JARVIS APK from source ZIP` را اجرا کن. این روش نیاز ندارد ده‌ها فایل پروژه را جداگانه آپلود کنی.

روش دیگر: ZIP سورس را در گوشی استخراج کن و تمام محتویات داخل پوشه پروژه (از جمله پوشه مخفی `.github`) را در ریشه مخزن بارگذاری کن؛ سپس workflow با نام `Build JARVIS APK` را اجرا کن.

پس از موفقیت، در همان اجرای workflow بخش Artifacts را باز کن و `JARVIS-debug-apk` را دانلود کن. ZIP آرتیفکت را استخراج و `app-debug.apk` را نصب کن. ممکن است لازم باشد نصب از منبع موردنظر را در تنظیمات اندروید مجاز کنی.

GitHub Actions هنگام build، Android SDK، NDK و CMake را روی runner نصب می‌کند و کتابخانه بومی را برای `arm64-v8a` می‌سازد. فایل مدل ۲.۵ گیگابایتی داخل APK قرار نمی‌گیرد؛ برنامه آن را در اولین اجرا دریافت می‌کند تا حجم APK و ریسک محدودیت نصب APK بسیار بزرگ کاهش یابد.

## وضعیت آزمون

این سورس در این محیط با Android SDK/NDK و روی گوشی واقعی کامپایل و آزمایش نشده است. بنابراین APK موفق، اجرای تأییدشده مدل یا سرعت مشخص ادعا نمی‌شود. تأیید نهایی build از طریق GitHub Actions و سپس نصب/آزمایش روی گوشی انجام می‌شود.
